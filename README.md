## ✨ DEVELOPMENT VALUES

```txt
01. USER EXPERIENCE
    화면이 동작하는 것에서 끝나지 않고
    사용자가 자연스럽게 이해하고 사용할 수 있는 경험을 고민합니다.

02. REUSABILITY
    반복되는 UI와 로직을 공통화해
    다음 개발의 비용을 줄이는 구조를 선호합니다.

03. EXTENSIBILITY
    현재 요구사항만 맞추기보다
    변경과 확장에 대응하기 쉬운 구조를 설계합니다.

04. PROBLEM SOLVING
    현상만 수정하기보다
    문제의 발생 조건과 데이터 흐름을 먼저 파악합니다.
```
